💡 How this works

  1. Client Action: Form submission triggers client-side JavaScript.
  2. HTTP Request: A JSON payload is dispatched via fetch('/api/notes', {method: 'POST'}).
  3. Server Processing: Python (Flask) validates the data and commits it to SQLite.
  4. HTTP Response: Server returns a 201 Created status and the new record.
  5. DOM Update: The SPA updates the notes board seamlessly without a full-page reload!
